This Mod is implemented in projects made in [Tritium](https://github.com/Tritium-Launcher/Tritium-Launcher). It provides utilities for Tritium to communicate with the game.

Current features:
* Command for dumping registry objects and textures in-game for Tritium to map for an object browser.
